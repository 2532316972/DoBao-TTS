### 阅读APP API及网络TTS引擎格式文档

#### 一、URL唤起方式
通过URL可直接唤起阅读APP进行一键导入，格式如下：
```
legado://import/{path}?src={url}
```
其中`path`类型及说明：
- `bookSource`：书源
- `rssSource`：订阅源
- `replaceRule`：替换规则
- `textTocRule`：本地txt小说目录规则
- `httpTTS`：在线朗读引擎
- `theme`：主题
- `readConfig`：阅读排版
- `dictRule`：词典规则
- `addToBookshelf`：添加到书架


#### 二、Web服务方式（需先在设置中启用）
假设本机端口为1234，远程访问需替换`127.0.0.1`为手机IP

##### 1. 书源/订阅源管理
| 操作 | URL | 方法 | 请求体格式 |
|------|-----|------|------------|
| 插入单个书源 | `http://127.0.0.1:1234/saveBookSource` | POST | JSON字符串（参考BookSource.kt） |
| 插入多个书源 | `http://127.0.0.1:1234/saveBookSources` | POST | JSON数组（参考BookSource.kt） |
| 插入多个订阅源 | `http://127.0.0.1:1234/saveRssSources` | POST | JSON数组（参考BookSource.kt） |
| 获取单个书源 | `http://127.0.0.1:1234/getBookSource?url=xxx` | GET | - |
| 获取单个订阅源 | `http://127.0.0.1:1234/getRssSource?url=xxx` | GET | - |
| 获取所有书源 | `http://127.0.0.1:1234/getBookSources` | GET | - |
| 获取所有订阅源 | `http://127.0.0.1:1234/getRssSources` | GET | - |
| 删除多个书源 | `http://127.0.0.1:1234/deleteBookSources` | POST | JSON数组（参考BookSource.kt） |
| 删除多个订阅源 | `http://127.0.0.1:1234/deleteRssSources` | POST | JSON数组（参考BookSource.kt） |

##### 2. 调试源（WebSocket）
- 书源调试：`ws://127.0.0.1:1235/bookSourceDebug`
- 订阅源调试：`ws://127.0.0.1:1235/rssSourceDebug`
- 消息格式：`{ key: [String], tag: [String] }`（key为搜索关键词，tag为源链接）

##### 3. 替换规则管理
| 操作 | URL | 方法 | 请求体格式 |
|------|-----|------|------------|
| 获取所有替换规则 | `http://127.0.0.1:1234/getReplaceRules` | GET | - |
| 删除替换规则 | `http://127.0.0.1:1234/deleteReplaceRule` | POST | JSON数组（参考ReplaceRule.kt） |
| 插入替换规则 | `http://127.0.0.1:1234/saveReplaceRule` | POST | JSON数组（参考ReplaceRule.kt） |
| 测试替换规则 | `http://127.0.0.1:1234/testReplaceRule` | POST | `{ rule: [ReplaceRule], text: [String] }` |

##### 4. 书籍管理
| 操作 | URL | 方法 | 请求体格式 |

#### 三、网络TTS引擎格式
```json
{
  "method": "POST",  // 请求方法
  "body": "POST原始请求体或GET的url参数，支持使用{{JS代码或变量}}"
}
```

##### 注意事项：
- JS代码中的转义字符`\`需多重转义为`\\`（因Json解析会自动去除一层转义）
- 从Web网页生成的url导入时，需手动删除`.replace(/\\/g, '')`，否则会导致JS执行失败
- 在线朗读规则为url规则,同书源url
- 阅读app支持这下面的三个可变参数的变量，它们是根据用户在使用阅读app时调节的实时生效参数。想要拿到书籍信息等其它信息，需靠官方文档中的Web服务方式

##### APP内置变量：
- `{{speakText}}`：文本内容
- `{{speakSpeed}}`：语速 范围5-50

##### 示例：
```json
{
  "concurrentRate": "5",
  "contentType": "audio/mpeg",
  "enabledCookieJar": false,
  "header": "",
  "id": 1760695197369,
  "lastUpdateTime": 1763733815437,
  "loginCheckJs": "",
  "loginUi": "",
  "loginUrl": "",
  "name": "温柔桃子（升级版）",
  "url": "http://192.168.0.110:3000/api/reader/tts/stream?text={{java.encodeURI(speakText)}}&speed={{speakSpeed}}&voice=zh_female_wenroutaozi_v2_mars_bigtts"
}
```


#### 四、对接经验与最佳实践

##### 1. 关键参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `concurrentRate` | 并发请求数 |  |
| `contentType` | 音频格式 | 必须为`"audio/mpeg"`，阅读APP只支持MP3 |
| `enabledCookieJar` | CookieJar | 根据服务需求设置，一般为`false` |

##### 3. 音频格式处理

如果TTS服务返回非MP3格式（如AAC、WAV等），需要使用FFmpeg实时转换：

```javascript
import ffmpeg from 'fluent-ffmpeg'

async function convertToMp3(inputBuffer, inputFormat = 'aac') {
  return new Promise((resolve, reject) => {
    const chunks = []
    const outputStream = new PassThrough()
    
    outputStream.on('data', chunk => chunks.push(chunk))
    outputStream.on('end', () => resolve(Buffer.concat(chunks)))
    
    ffmpeg(Readable.from([inputBuffer]))
      .inputFormat(inputFormat)
      .toFormat('mp3')
      .pipe(outputStream)
  })
}
```
